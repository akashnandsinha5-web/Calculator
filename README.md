# Calculator

A simple and modern Calculator UI built using **HTML and CSS**. This project focuses on creating a clean, attractive, and user-friendly calculator interface.

## 📸 Project Preview

The calculator features a dark-themed design with a display screen, number buttons, arithmetic operators, and a clear button.

## ✨ Features

- Clean and modern user interface.
- Dark-themed calculator design.
- Number buttons (0–9).
- Arithmetic operator buttons (+, -, *, /).
- Percentage (%) button.
- Clear (AC) and Delete (DEL) buttons.
- Responsive and user-friendly layout.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚧 Project Status

**Currently in Development**

The calculator's user interface has been completed using HTML and CSS.

JavaScript functionality will be added in the next phase to support:
